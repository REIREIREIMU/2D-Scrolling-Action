・プロジェクト名
「Eating Runner」

[東北ゲームアワード2026ゲスト賞（主催：仙台ゲームコート様/ 2026年2月受賞）]

・概要
　-「Eating Runner」は体重変化をテーマにした
　　2D横スクロールアクションゲームです。  
　　プレイヤーは食べ物を取得すると太り、移動することで痩せていきます。
　　体型によって移動速度やジャンプ力が変化するため、
　　状況に応じた体重管理が攻略の鍵になります。

・特徴
　- 体型によって性能が変化する独自システム
　- 太りすぎ・痩せすぎでゲームオーバー
　- リスクとリターンを伴うゲーム設計
　- シーン管理の一元化
　- CSV/文字ベースのステージ構築

・開発環境
　- 言語: C++
　- ライブラリ: DxLib
　- プラットフォーム: Windows

・担当
　- 個人制作時: 設計・実装すべて
　- チーム制作時: 調整・改善担当

・技術ポイント
  - シーン遷移の一元管理
  - AABB衝突判定（動的サイズ対応）
  - 入力管理クラスによるデバイス統一
  - データ駆動設計（マップ)

・操作方法
=キーボード操作
  - 移動: [←] [→] / [A] [D]
　- ジャンプ: [Space] / [W]

=コントローラー操作（Xbox）
  - 移動: 左スティック
　- ジャンプ: [X]
